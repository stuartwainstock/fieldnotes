# Tickets

Working tickets live in `tickets/`, numbered in roadmap order (`01-...` through `20-...`). Each file is self-contained: context, acceptance criteria, relevant files, dependencies.

When a ticket is finished, move its file from `tickets/` to `done/` and check it off in the corresponding entry in `../TASKS.md`.

The full phased roadmap and the locked architecture decisions live in `../TASKS.md` — start there for the big picture, come here for the file to actually work from in Cursor.
